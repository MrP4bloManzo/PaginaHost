# Pablo Manzo — Personal Portfolio

Portafolio personal estático, responsive y listo para desplegar en **GitHub Pages**.

## Incluye

- Hero con identidad tecnológica/cyber.
- Sección personal orientada a Ingeniería en Tecnologías del Internet.
- Proyectos: PETSTATION, PETSTATION Dashboard, ADAS y FEC Demo.
- Sección de liderazgo estudiantil / 404 Red Activa.
- Stack técnico.
- Timeline.
- Contacto.
- Animaciones ligeras con IntersectionObserver.
- Sin frameworks ni build step: HTML + CSS + JavaScript.

## Cómo usarlo

1. Sube todos los archivos a un repositorio de GitHub.
2. Cambia en `index.html`:
   - `TU_CORREO@EJEMPLO.COM`
   - enlace de GitHub
   - enlace de LinkedIn
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona `main` y `/ (root)`.
6. Guarda y espera el despliegue.

## Personalización rápida

Los colores principales están arriba de `styles.css` en `:root`.
El contenido de proyectos y textos principales está en `index.html`.

## Estructura

```text
pablo-manzo-portfolio/
├── index.html

├── script.js
├── README.md

```

> Consejo: reemplaza los enlaces sociales y, si quieres una versión todavía más personal, agrega una fotografía profesional o un avatar en la sección Hero.
